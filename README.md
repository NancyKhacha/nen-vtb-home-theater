# НЭН × Домашний театр ВТБ

Тестовая верстка лендинга к статье «Каждый год 31 декабря…» (текст: Камилла Эфрос). Страница закрыта от поисковиков.

- `index.html` — собранная страница.
- `styles.css`, `app.js` — стили, эффекты по прокрутке и легкие анимации на иллюстрациях.
- `assets/img` — картинки в webp.
